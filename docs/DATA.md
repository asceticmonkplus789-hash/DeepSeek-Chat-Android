# 数据保存、备份与问题反馈

## 数据流向

| 内容 | 保存或发送位置 |
|---|---|
| API Key、主题、语言及其他设置 | localStorage |
| 会话、消息树和附件原件 | IndexedDB |
| 对话请求、附件上传、语音处理内容 | 配置的 API 服务 |
| 历史导出 ZIP | 用户选择的本地保存位置 |

浏览器中的本地数据按用户配置与站点 origin 隔离，安卓中的数据属于应用存储。不要将浏览器、不同站点或不同应用安装的数据自动视为共享。

API Key 当前使用 localStorage 保存，源码没有实现专门的硬件密钥库加密方案。请在可信设备和可信应用构建中使用 Key。避免把 Key、聊天原文和原始附件提交到仓库、日志或问题反馈中。

## 更新、卸载与签名

目前交付 debug APK，流水线没有持久化签名密钥。`5d30324`、`2a454f8`、`7dc302a` 对应的已交付 APK 证书比较存在差异，因此更新时可能被系统拒绝覆盖安装。

卸载前先导出历史，将 ZIP 保存到应用外部，并单独保存 API Key、设置和重要原始附件。确认备份可读取后，再决定卸载旧版并安装新版本。卸载、清除应用数据或更换浏览器配置均可能使本地数据丢失。

## 历史导出与导入

导出包含完整会话消息树、当前分支以及本地存在的图片原件。导出不包含 API Key、应用设置、非图片附件原件或所有本地运行状态。详细字段和限制见 [归档格式说明](../src/services/chat/history/README.md)。

导入在用户确认后执行格式校验，成功后以一个事务替换全部本地会话和附件。校验或提交失败时保留原记录。执行导入前仍建议留存当前记录的独立备份。

设置中的“删除所有对话”清空本地会话、附件原件与未发送草稿，保留 API Key 和应用设置。此操作不删除已经上传到 API 服务的文件。

## 问题反馈

提交问题时说明应用提交号、手机型号、安卓版本、复现步骤、预期表现和实际表现。可以附脱敏截图或短录屏。API 问题还可提供 HTTP 状态码和已脱敏的错误文字。

本仓库目前公开。反馈前检查截图、录屏、导出 ZIP 和日志中是否含 API Key、聊天内容、个人资料、位置或附件。涉及凭据泄露时，先通过 API 提供方的账号管理撤销或更换相关 Key，再与维护者约定合适的沟通渠道。不要通过公开 Issue 粘贴凭据。
